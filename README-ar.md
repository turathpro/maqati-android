# مقاطع — مشروع أندرويد ستوديو (يبني ملف APK حقيقي)

هذا مشروع Android Studio كامل. يفتح التطبيق الموجود أصلًا على هاتفك (الذي يشغّله Termux على
`http://127.0.0.1:8765`) داخل **نافذة تطبيق حقيقية**: أيقونة خاصة على الشاشة الرئيسية، بدون شريط
متصفّح، مع دعم رفع الملفات وتنزيلها بشكل طبيعي.

**مهم تعرفه:** هذا المشروع **لم يُبنَ أو يُجرَّب فعليًا** من هذا الطرف — الجهاز السحابي اللي
أشتغل عليه محجوب عن خوادم Google (اللي لازم ينزّل منها Android SDK)، فكتبته بعناية باتباع
الطريقة القياسية المعروفة، لكن أول بناء حقيقي له سيكون على جهازك. هذا طبيعي ومتوقّع — خطوات
البناء تحت واضحة وسهلة.

## لماذا هالطريقة ولا طريقة ثانية؟

- **لا تحتاج Termux يصير له أي تعديل** — هذا غلاف (wrapper) فقط يعرض نفس الصفحة بشكل أجمل.
- **يتحدّث تلقائيًا** — أي تحديث تسويه للتطبيق نفسه (عبر زر "تحديث" أو ملف جديد) يظهر فورًا بهذا
  التطبيق بدون أي حاجة تبني .apk من جديد، لأنه بس "نافذة" تعرض ما يشغّله Termux.
- جرّبت فعليًا بناء نسخة تحمل Python و ffmpeg بداخلها وتشتغل بدون Termux إطلاقًا — لكن هذا صعب
  وغير موثوق على أندرويد (قيود حقيقية على تشغيل برامج خارجية داخل تطبيق، ومشاكل ترخيص) فلم أنصح به.

## خطوات البناء (على جهاز الكمبيوتر، مرة واحدة)

1. نزّل وركّب **Android Studio** (مجاني): https://developer.android.com/studio
2. افتحه → **Open** → اختر مجلد هذا المشروع (`MaqatiAndroid`).
3. استنى أول مرة لين يخلّص Android Studio تحميل كل الأدوات المطلوبة (Gradle، SDK...) — يحتاج نت
   ويمكن يأخذ عدة دقائق أول مرة.
4. لو طلع يسألك يحدّث Gradle أو Android Gradle Plugin لنسخة أحدث — وافق، عادي.
5. من القائمة: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. بعد ما يخلص، اضغط الرابط اللي يطلع ("locate") أو روح لـ:
   `app/build/outputs/apk/debug/app-debug.apk`
7. انقل هذا الملف لهاتفك (عبر كيبل، بلوتوث، أو أي طريقة)، وثبّته (قد يسألك تسمح بالتثبيت من مصدر
   غير معروف — هذا طبيعي لأي APK مش من متجر Google Play).

## ملاحظة أخيرة

تأكد إن Termux يشغّل مقاطع فعليًا (افتح Termux مرة وخله يشتغل، أو تأكد من خدمة الإقلاع التلقائي
اللي سبق جهّزناها) قبل ما تفتح هذا التطبيق — إذا ما حصل التطبيق السيرفر شغّال، بيطلع لك زر
"فتح Termux" و"أعد المحاولة" بشكل واضح.
